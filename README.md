# Usage Guide
1. To use this app, clone this repo to your local or download the `CursorJump.app/` folder. 
2. `CursorJump.app/` is the macOS app. Open it by double clicking it, accept any notices since it was downloaded from the internet.
3. Once the app is opened, you will see a cursor icon in the menu bar. 
4. Click on it and choose to option to open Privacy settings to give it access and then enable the required access to get started with it. 
5. Also, make sure to click the `Launch at Login` in the menu bar menu to automatically lauch at the Login. Use the `CMD`+`SHIFT`+`ARROW KEYS (< or >)` to swicth among the displays.
